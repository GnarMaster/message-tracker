# message-tracker

Discord 서버의 메시지 활동을 추적하고, 레벨 시스템 및 다양한 게임 기능을 제공하는 Discord 봇입니다.  
Google Sheets를 데이터베이스로 활용하며, Render 플랫폼에 배포됩니다.

---

## 주요 기능

### 메시지 트래킹
- 메시지, 멘션, 링크, 이미지, Reels 채널 활동을 실시간 모니터링
- 1분 주기로 Google Sheets와 데이터 동기화

### 레벨 시스템
- 메시지 전송 시 경험치 획득
- 레벨별 경험치 요구량: `0.5 × level² + level × 11` (최대 100레벨)
- `/내레벨` — 내 레벨 및 경험치 확인

### 생일 관리
- MMDD 형식으로 생일 등록
- 매일 자정(KST) 생일자에게 자동 축하 메시지 전송
- `/생일추가` — 생일 등록

### 게임 & RPG 시스템
| 기능 | 설명 |
|------|------|
| 출석 (`attendance`) | 매일 출석 체크 및 보상 |
| 도박 (`gamble`) | 코인을 건 도박 게임 |
| 인벤토리 (`inventory`) | 아이템 관리 |
| 직업 (`job_info`) | 전사, 마법사, 도적 등 직업 시스템 |
| 메뉴 (`menu`) | 봇 명령어 안내 |
| 순위 (`rank`) | 활동 순위 확인 |
| 음성 경험치 (`voice_exp`) | 음성 채널 참여 시 경험치 획득 |
| 골드 시스템 (`goldsystem`) | 재화 관리 |
| RPG (`rpg`) | RPG 전투 시스템 (반격 버프, 카피닌자 스킬 등) |

### 슬래시 명령어

**활동 / 레벨**
| 명령어 | 설명 |
|--------|------|
| `/이번달메시지` | 이번 달 메시지 순위 조회 |
| `/내레벨` | 내 레벨 및 경험치 확인 |
| `/생일추가` | 생일 등록 (MMDD 형식) |
| `/출석` | 매일 출석 체크, 10~50 골드 랜덤 보상 |
| `/랭킹정산` | 이번 달 랭킹 정산 및 시트 초기화 *(관리자 전용)* |

**RPG / 직업**
| 명령어 | 설명 |
|--------|------|
| `/전직` | 레벨 5 이상 백수 전용 1차 전직 (전사·마법사·궁수·도적·특수) |
| `/2차전직` | 레벨 10 이상 1차 전직자 전용 2차 전직 |
| `/직업변경` | 직업변경권 소모 후 직업 변경 |
| `/직업소개` | 전체 직업 및 스킬 정보 확인 |
| `/쿨타임` | 내 직업 스킬 쿨타임 확인 |
| `/보스소환` | 보스 소환 (보스 전용 채널) |
| `/보스공격` | 보스 공격 (2시간 쿨타임, 직업별 공격 방식) |
| `/내무기` | 무기 상태 확인 및 강화 (대장간 채널 전용, 최대 10강) |

**골드 / 경제**
| 명령어 | 설명 |
|--------|------|
| `/인벤토리` | 보유 골드 및 아이템 목록 확인 |
| `/골드상점` | 골드로 아이템 구매 (직업변경권·상품권·경험치구매권) |
| `/뽑기기계` | 가차 채널에 뽑기 머신 설치, 10골드로 1회 뽑기 |
| `/도박시작` | 도박 이벤트 개시, 최대 8개 선택지 *(관리자 전용)* |

**메뉴 추천**
| 명령어 | 설명 |
|--------|------|
| `/점메추` | 오늘의 점심 메뉴 랜덤 추천 |
| `/저메추` | 오늘의 저녁 메뉴 랜덤 추천 |
| `/메뉴추가` | 추천 메뉴 목록에 항목 추가 |
| `/메뉴삭제` | 추천 메뉴 목록에서 항목 삭제 |
| `/메뉴판` | 현재 등록된 메뉴 전체 목록 조회 |

## 기술 스택

- **언어**: Python 3
- **Discord 라이브러리**: discord.py
- **데이터 저장소**: Google Sheets (gspread, oauth2client) + 로컬 JSON 캐시
- **스케줄러**: APScheduler
- **서버 유지**: Flask (`keep_alive`)
- **배포**: Render

---

## 설치 및 실행

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정

프로젝트 루트에 `.env` 파일을 생성하고 아래 값을 입력합니다.

```env
DISCORD_BOT_TOKEN=your_discord_bot_token_here
```

Google Sheets 연동을 위한 서비스 계정 JSON 키 파일도 별도로 준비해야 합니다.

### 3. 봇 실행

```bash
python main.py
```

---

## Render 배포

`render.yaml`이 포함되어 있어 Render 플랫폼에 바로 배포할 수 있습니다.

1. Render 대시보드에서 이 저장소를 연결
2. 환경 변수 `DISCORD_BOT_TOKEN`에 실제 봇 토큰 입력
3. 배포 완료
